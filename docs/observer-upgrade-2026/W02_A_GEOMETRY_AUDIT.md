**Scope:** audit + freeze v5, NOT a dimension-aware refactor. **Baseline:** main `4149442f026be2f404c249511fdbc9ad2b7f5867`, PR #15 merged; main CI `38861069823` and Pages `38861069825` both completed success. V01-E hardware FPS/long soak remains OPEN. Branch: `feat/w02-a-map-schema-audit`; PR #16. Source inventory from the complete `main` Git tree, direct source reads and callsite scans. See [ADR](W02_A_SCHEMA_ADR.md), [save evidence](W02_A_LEGACY_V5_QA.md) and [handoff](W02_A_HANDOFF.md).

## 1. Existing geometry and invariants

- The only authoritative v5 terrain array is `world.tiles: Terrain[]`, row-major `y * 48 + x`. `WorldState.schemaVersion === 5` has **no dimension metadata**. `GRID_WIDTH=48`, `GRID_HEIGHT=48`, `TILE_PIXELS=12` in `src/sim/grid.ts`. The displayed map is 576×576 world pixels.
- `grass`, `forest`, `road` are walkable; `water` is blocked. Cardinal BFS neighbor order **north, east, south, west** is behavior-critical for seeded continuation.
- The active world includes `Site` IDs (home/work/commons/market), citizen `homeId/workId/householdId/partnerId`, `ResourceNode`, construction plots, market stock and treasury, relations, social groups, governance IDs and queued policies. These IDs must not be regenerated by v5 import.
- The engine computes positions in tile coordinates; Phaser projects through 12-pixel art units. Zoom/scroll are **runtime** state, not persisted world metadata.
- The current `stateDigest` in `src/sim/engine.ts` omits `world.tiles` (!). It is not sufficient as a save/geometry golden hash. The W02-A fixture pins SHA-256 of the entire JSON save **and** entire `world` JSON plus the continued world.

## 4. Performance impact and uncertainty

| Aspect | Current 48×48 | 96×96 estimate | Type/evidence |
| --- | --- | --- | --- |
| Terrain cells | 2,304 | 9,216 (4×) | exact mathematics |
| Generator tile/RNG loop | 2,304 iterations | 9,216 (~4× baseline loop) | theoretical; generator algorithm will change |
| BFS `previous+queue` two `Int32Array` | 18,432 bytes/call | 73,728 bytes/call (+55,296) | exact allocation for those 2 arrays, excluding GC/object overhead |
| BFS worst visited nodes | <=2,304 | <=9,216 (4×), longer routes | upper-bound complexity, not benchmark |
| Terrain paint primitive visits | 2,304 | 9,216 (4×) if no culling | theoretical; renderer-specific cost not measured |
| Pixel footprint at 12px/tile | 576×576 | 1152×1152 | exact; NOT necessarily 4× on-screen pixels |
| Existing frozen save, 50 NPC tick720 | **263,532 UTF-8 bytes** | unknown; extra 6,912 terrain entries alone likely ~50–60 KiB before extra sites/POIs | first measured from CI engine; second theoretical only |
| Browser/Windows FPS and memory | V01-E CI matrix inconclusive; device and soak NOT RUN | unknown | W02-F must profile |

Do not extrapolate a 4× total frame-time or CPU penalty from cell count: update frequency, camera, GPU batching, path calls per tick, site count and cache behavior all matter. No renderer optimization or performance certification in W02-A. Indexing bugs are **correctness blockers** even if an FPS number looks acceptable.

## 5. W02-A boundary

This PR adds documentation and a real, frozen v5 fixture with replay tests. No changes to `WorldState`, grid helpers, BFS, map generator, renderer, gameplay time model or save envelope. Subsequent implementation must use [the agreed ADR](W02_A_SCHEMA_ADR.md).
