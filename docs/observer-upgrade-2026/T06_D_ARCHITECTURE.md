# T06-D renderer optimization, evidence and risk

Implementation candidate (2026-10-21): static forest-tree viewport visibility culling in WorldScene only. Existing 96x96 terrain and metadata roads were ALREADY rasterized once into textures; no redundant second terrain cache was introduced. Unlike NPCs and ambient actors, these tree images are noninteractive and never enter authoritative state. The camera viewport is expanded by 30 world pixels around the sprite anchor to avoid disappearing silhouettes. View changes toggle `visible` on existing tree objects; no destroy/create, no timers, no simulation or RNG mutation. Scene shutdown clears references; diagnostics expose total vs visible trees.

Rationale: full 96x96 scene builds all decorative forest sprites regardless of zoom level. Their camera-excluded draw/render processing is an avoidable presentation workload when observing a close-up. **Do not claim speedup until the paired browser runs prove one.** Tradeoff: O(number of forest sprites) visibility checks while camera moves, and memory unchanged for allocated sprites; a regression mandates rollback.

Measurement: `tests/e2e/t06d-render-benchmark.spec.ts` captures 3 warmed rAF samples for 96x96, seed 12345, 100 NPC, 1x/20x, fit/zoom/follow, 1920x1080, effects on/off; T06-D headless workflow checks out exact unmodified main baseline and candidate on one Ubuntu runner with Chromium 141. These are browser main-thread rAF intervals, **NOT** physical Windows/PC GPU certification. Full requested matrix, 48x48 legacy browser profile, audio, Windows soak remain outside this controlled CI subset; Node 48/96 matrices already exist in T06-A and run in Fast CI.

Correctness: `tests/e2e/t06d-forest-culling.spec.ts` requires visible tree count to shrink while zooming and restore on Fit without new textures or canvas, while a paused world's tick/digest remains identical. Run existing frozen SHA-256 and save compatibility Vitest tests as part of Fast CI; never alter goldens. CI conclusions must correspond to actual final SHA.
